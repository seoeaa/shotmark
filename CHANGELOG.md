# Changelog

## 0.3.0 — 2026-10-01

Первый публичный prerelease.

- Собственная цветная иконка и упрощённая SVG-иконка трея.
- `.deb` для Ubuntu 24.04 с системными зависимостями, без локальной `.deps`.
- GitHub Actions: регрессионные тесты, сборка, установка/удаление пакета на runner,
  synthetic selftest и автоматическое прикрепление пакета к релизу по тегу.
- SHA256SUMS, нормализация прав и тест побайтовой воспроизводимости сборки.
- MIT license и инструкции установки готового пакета.

## 0.2.0

- Отдельный GTK3/Ayatana-трей, запускающий GTK4-редактор.
- Пользовательская установка без sudo и без автозапуска.
- Защита от повторного запуска трея, сообщения об ошибках дочернего редактора.

## 0.1.1

- Исправлены таймауты portal и удержание приложения до ответа.
- Clipboard с явным `image/png`, окно остаётся открытым для вставки.
- Сохранение PNG без перезаписи и без удаления исходника портала.
- Исправления crop, стрелок, цветов, ввода текста и локального Cairo bridge.

## 0.1.0

Локальный прототип аннотатора скриншотов на GTK4/Cairo и xdg-desktop-portal.
