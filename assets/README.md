# Shotmark icon

The desktop icon was generated specifically for Shotmark, not copied from an existing application.

- Model: `openai/gpt-image-2.5/sunburst/text-to-image`, through fal.ai.
- One image, 1024×1024 PNG with alpha, high quality.
- Request: `01a0f491-c3be-7b21-9da2-099661a4ab22`.
- Original source: https://v3b.fal.media/files/b/0aac8eff/0WDFo_HsxLme4588TVfVC_auOtMq9k.png
- The CDN URL may expire. The original is committed as `shotmark-generated-1024.png`.
- Concept: violet screenshot-selection corners and a golden pencil on a deep-indigo rounded tile; no text.
- `icons/hicolor/scalable/apps/io.github.shotmark.Shotmark-symbolic.svg` is a manually drawn simplified companion for small monochrome tray displays, not an automatic vector tracing.

Regenerate PNG sizes locally with `python3 scripts/prepare_icons.py` (Pillow required).
CI and the application never call a generation service. No API key is needed to build or run Shotmark.
